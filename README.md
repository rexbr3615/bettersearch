Searches affect the Creative Inventory, Recipe Book, and even the chat. Each of these can be individually enabled or disabled through a fully customizable, intuitive, and easy-to-use menu accessed by pressing <kbd>Alt</kbd> + <kbd>O</kbd>. 
Below are some useful settings that make this mod stand out from similar alternatives:
- Fully configurable multi-language support
- Fully configurable fuzzy search system
- Vanilla-faithful interface
- Pre-configured for almost any language
- Full support for all Minecraft languages and any mod
